# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Plinglist, please report it responsibly by emailing **[hey@goork.de](mailto:hey@goork.de)** instead of opening a public GitHub issue.

Please include:
- A clear description of the issue and affected component (`packages/core`, `server`, `app`)
- Steps to reproduce or a minimal proof of concept
- Potential impact

We aim to acknowledge reports within 48 hours and coordinate a fix before public disclosure.
